Privacy Policy

Last updated: November 9, 2026

"Ranking Shorts Uploader" is a private tool operated by the owner of the Awesome Rankings YouTube channel. It is not offered to the public.

Data accessed

The tool uses Google OAuth to access only the owner's own YouTube account, with the scopes youtube.upload (to upload videos) and youtube.readonly (to check the status of uploaded videos).

Data storage and sharing

The OAuth token is stored only on the owner's computer. No data from any Google user is collected, sold, shared with third parties, or used for advertising. No other users' data is accessed.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
